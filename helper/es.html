Para PC con Windows o Linux de 64 bits Intel/AMD que se inician desde esta memoria USB. No para Mac con Apple Silicon. No para Chromebooks. Algunos Mac con Intel pueden mostrar esta memoria USB; muchos no lo harán.

Esta memoria USB utiliza los archivos de arranque firmados de Debian. Que su equipo la inicie depende de la configuración de confianza del firmware de ese equipo y de las actualizaciones de revocación. Beamo Wipe no cambia Secure Boot ni elude un rechazo.

La memoria USB no aparece o no está en la lista

  1. Mantenga esta memoria USB conectada mientras el equipo se reinicia. No la retire.
  2. Utilice un puerto USB-A o USB-C del propio equipo. Si puede, evite el teclado, el monitor o un concentrador (hub).
  3. Pruebe otro puerto del mismo equipo.
  4. Reinicie y busque esta memoria USB en el menú de arranque o en Usar un dispositivo de Windows.
  5. Si este equipo sigue sin mostrar la memoria USB, ábrala en un equipo que ya muestre archivos y compruebe que START-HERE.html está ahí. Después pruebe otro puerto directo.

Windows 11: Configuración → Sistema → Recuperación → Inicio avanzado → Reiniciar ahora → Usar un dispositivo, si aparece. Windows 10: Configuración → Actualización y seguridad → Recuperación → Inicio avanzado → Reiniciar ahora → Usar un dispositivo. Esos menús son para PC UEFI. Consulte Windows 11 y Windows 10.

Detalle técnico

Algunos equipos ocultan el arranque desde USB hasta que el firmware lo permite. Es una opción del firmware del equipo, no de Beamo. Si es posible que vuelva a usar esta instalación de Windows, confirme antes la clave de recuperación de BitLocker. Esta página no puede cambiar el firmware.

Volver a los problemas

La tecla del menú de arranque no hace nada

  1. Las teclas varían según el fabricante. No son las mismas en todos los PC. Utilice la tabla de teclas habituales.
  2. Empiece a presionar la tecla repetidamente en cuanto reinicie, antes de que termine de aparecer Windows o un logotipo.
  3. En HP, pruebe primero Esc y luego F9.
  4. Si el equipo arranca demasiado rápido para usar una tecla, utilice los pasos de Configuración de Windows en lugar de cambiar el firmware.
  5. Revise la etiqueta, la pantalla de inicio o las instrucciones del fabricante del equipo si una tecla de la lista no hace nada.

Dell, Lenovo y Acer suelen usar F12. ASUS suele usar F8 o Esc. MSI suele usar F11. Gigabyte suele usar F12. Mac con Intel: Option (⌥) al arrancar. No para Apple Silicon.

Detalle técnico

Algunos equipos acortan el momento en que aceptan una tecla. Usar un dispositivo del Entorno de recuperación de Windows evita ese problema de tiempo en muchos PC UEFI. No considere los cambios de firmware, del orden de arranque o del menú de configuración como el siguiente paso automático.

Volver a los problemas

El equipo rechazó la memoria USB

  1. Si es posible que vuelva a usar esta instalación de Windows, confirme que puede acceder a la clave de recuperación de BitLocker antes de cualquier cambio en el firmware. Si no encuentra la clave, deténgase. Utilice otro puerto USB o los pasos de Windows. Consulte BitLocker.
  2. Anote el mensaje exacto de la pantalla. Llegar a un menú de arranque no significa que haya empezado un borrado.
  3. Pruebe otro puerto USB directo y reinicie.
  4. En equipos con BIOS antigua, es posible que falte Usar un dispositivo. Utilice la tecla del menú de arranque en lugar de cambiar el firmware.
  5. Siga las instrucciones de inicio del fabricante del equipo. Esta ayuda no cambia Secure Boot ni elude un rechazo.

Consulte Secure Boot para saber qué incluye esta memoria USB. No considere los cambios de firmware o de Secure Boot como el siguiente paso automático.

Volver a los problemas

El lanzador falló

  1. Conectar la memoria USB no inicia la aplicación. En Windows, abra Start Beamo Wipe.exe. En un escritorio Linux compatible, abra Start Beamo Wipe Linux.
  2. Pueden aparecer avisos de permisos o de confianza en la aplicación. La configuración del escritorio y del montaje de Linux puede impedir que se ejecute un archivo desde una memoria USB.
  3. Una comprobación no verificada no es un resultado correcto. En Windows, guarde su trabajo y utilice Reiniciar; luego elija esta memoria USB en el menú de arranque. En escritorios Linux compatibles, se puede ofrecer un reinicio guiado cuando sus comprobaciones son correctas; es posible que se necesite permiso de administrador.
  4. El lanzador no borra nada. Si no se abre, utilice las teclas habituales o los pasos de Configuración de Windows.
  5. Si Beamo Wipe ya se inició desde esta memoria USB y se cierra una y otra vez, utilice la pantalla de recuperación: vuelva a intentarlo, utilice las pantallas de texto con teclado o vea los detalles técnicos.
Detalle técnico

El lanzador solo comprueba la memoria USB original, si se puede leer la configuración de inicio y si existe una vía de reinicio compatible. Esas comprobaciones no aseguran que la memoria USB vaya a arrancar. Para seguir los pasos de arranque basta con abrir esta página en un navegador desde la memoria USB. Después del arranque, la recuperación no puede identificar discos ni confirmar el resultado de un borrado.

Cuando esta memoria USB se inicie

Elija un disco → Confirme su identidad → Revise y borre. No se borra nada hasta que usted confirme.

Iniciar desde su escritorio

En Windows, abra Start Beamo Wipe.exe en esta memoria USB. En un escritorio Linux compatible, abra Start Beamo Wipe Linux. El lanzador muestra comprobaciones separadas de la memoria USB original, de si se puede leer la configuración de inicio y de si hay disponible una vía de reinicio compatible. Cada comprobación explica qué hacer a continuación; Detalles técnicos muestra las pruebas.

Una comprobación no verificada no es un resultado correcto. En Windows, guarde su trabajo y utilice Reiniciar; luego elija esta memoria USB en el menú de arranque. En escritorios Linux compatibles, se puede ofrecer un reinicio guiado cuando sus comprobaciones son correctas; es posible que se necesite permiso de administrador. Estas comprobaciones no aseguran que la memoria USB vaya a arrancar.

Abrir la aplicación requiere una acción suya; conectar la memoria USB no la ejecuta automáticamente. Pueden aparecer avisos de permisos o de confianza en la aplicación. La configuración del escritorio y del montaje de Linux puede impedir la ejecución directa.

El lanzador no borra nada. El borrado se realiza después de reiniciar desde esta memoria USB, donde usted elige y confirma el disco. También puede seguir las instrucciones de arranque de abajo sin abrir ninguna aplicación.

Si es posible que vuelva a usar esta instalación de Windows

Confirme que puede acceder a la clave de recuperación de BitLocker de este PC antes de cambiar el firmware, el orden de arranque, Secure Boot o la configuración del TPM. Esos cambios pueden hacer que Windows pida la clave de recuperación de 48 dígitos la próxima vez que se inicie.

El soporte técnico de Microsoft no puede recuperar, proporcionar ni volver a crear una clave perdida. La clave puede estar guardada en una cuenta Microsoft en otro dispositivo, en manos del departamento de TI de su trabajo o centro educativo, impresa o guardada en una memoria USB que guardó cuando se activó el cifrado.

Esta ayuda no desactiva BitLocker, no extrae claves ni recomienda cambiar Secure Boot. Si todavía necesitará este Windows más adelante y no encuentra la clave, no cambie el firmware. Utilice en su lugar los pasos de Windows de abajo, otro puerto USB o las instrucciones de inicio del fabricante.

Si utiliza un lector de pantalla

El menú de arranque tiene una entrada llamada Beamo Wipe: speech for screen readers (voz para lectores de pantalla). En cuanto aparezca el menú, presione S. Los equipos UEFI con altavoz integrado emiten dos pitidos cortos mientras se muestra el menú; muchos portátiles y el menú de BIOS antigua no emiten ningún sonido, así que presione S varias veces después del logotipo del firmware.

El menú espera cinco segundos y luego inicia la guía normal. Si eso ocurre, presione F8 en la guía para cambiar a la vista con voz. La voz necesita altavoces o auriculares que funcionen. Elegir cualquiera de las dos entradas no borra nada.

Si Beamo Wipe se cierra una y otra vez

Después de tres intentos fallidos, los reintentos automáticos se detienen. La pantalla de recuperación de Beamo Wipe (en inglés) le permite volver a intentarlo, utilizar las pantallas de texto con teclado o ver los detalles técnicos. Escriba el número de la opción y presione Enter.

Es posible que un borrado anterior siga en curso o esté incompleto. Mantenga todos los discos conectados. Esta pantalla de recuperación no puede identificar discos ni confirmar el resultado de un borrado. Volver a intentarlo no inicia un borrado nuevo.

Las opciones Restart computer y Shut down requieren confirmación. Se bloquean si es posible que el borrado siga en curso o si la comprobación falla. Al reiniciar se pierden los informes no guardados y los registros temporales. Anote antes los detalles técnicos.

Si eligió la voz al arrancar, las opciones de recuperación se leen en voz alta cuando las herramientas de voz están disponibles. El asistente de texto con teclado no tiene voz. Si la voz no se inicia, pida a alguien que le lea la pantalla de recuperación.

Si una pantalla del asistente muestra un problema

Los errores en Beamo Wipe usan tres secciones, en este orden. La identidad del disco, las exclusiones, la incertidumbre y el mensaje exacto siguen visibles.

  1. Qué pasó — el mensaje exacto de esta sesión.
  2. Qué significa para su disco — si se borró algo y qué no debe suponer.
  3. Qué hacer ahora — pasos seguros. No eluda la protección. Si tiene dudas, mantenga los discos conectados.

Los Detalles técnicos (códigos de resultado, marcadores de exportación, registros) están disponibles si los pide. No sustituyen a las tres secciones. El menú de recuperación de la memoria USB live tras fallos repetidos de inicio es aparte: su opción Technical details and logs no es esta presentación del asistente.

Qué hace esta memoria USB

Compruebe que tiene las copias que necesita. Elegirá un disco. Se borrará todo lo que contiene. No podrá recuperar los archivos.

Si ese disco contiene un sistema operativo, borrarlo también elimina Windows o Linux, las aplicaciones, los archivos y las particiones de recuperación de ese disco. Solo se borra el disco que usted confirma. Los demás discos no. Volver a instalar un sistema operativo es una tarea aparte.

Si este equipo tiene batería, conéctelo a la corriente antes de borrar. Mantenga la tapa abierta. Un corte de corriente detiene el borrado. La pantalla puede apagarse; presione una tecla o mueva el ratón para que vuelva a verse. Es la pantalla, no la suspensión.

Si quiere un informe después, necesita una memoria USB FAT32 o exFAT aparte con un solo volumen (de cualquier tamaño). Manténgala desconectada hasta que la pantalla de resultado la pida. Una memoria USB que ya está conectada no sirve para el informe.

La memoria USB live pide a Linux que ignore el cierre de la tapa y una pulsación breve del botón de encendido, y desactiva la suspensión. El firmware o mantener pulsado el botón de encendido aún pueden detener el borrado. Utilice Detener el borrado y espere el resultado antes de apagar. Un corte de corriente puede dejar el disco parcialmente borrado y hacer que se pierdan los informes no guardados; un borrado interrumpido no se reanuda automáticamente.

Esta ayuda sin conexión no puede leer el estado de la batería ni de la corriente. El asistente live muestra las lecturas informadas cuando están disponibles; una lectura desconocida no demuestra que haya corriente conectada ni que vaya a durar.

Si el equipo no se inicia después del borrado

Si el disco borrado era desde el que se inicia el equipo, es posible que el equipo muestre una pantalla negra, un mensaje de «no hay sistema operativo» o una reparación de inicio en lugar de iniciarse con normalidad. Es lo esperado: el borrado eliminó el sistema operativo junto con todo lo demás de ese disco.

Para volver a usar ese equipo, primero instale un sistema operativo con un medio de instalación o con la recuperación del fabricante del equipo. Si tiene dudas, pida ayuda a una persona de confianza antes de cambiar nada.

Si el disco borrado era una unidad adicional, el equipo debería iniciarse con normalidad. La unidad borrada aparecerá vacía hasta que se prepare para volver a usarla.

Guardar el informe

  1. Conecte la memoria USB del informe solo cuando la pantalla de resultado la pida.
  2. Compruebe: el asistente acepta exactamente una memoria USB FAT32 o exFAT nueva.
  3. Guarde: el informe se escribe en esa memoria USB. Puede tardar un par de minutos en una memoria lenta; nunca retire ninguna memoria USB mientras se guarda.
  4. Verifique: la copia se vuelve a leer antes de contar como guardada.
  5. Retirada segura: solo la confirmación de guardado indica que la memoria USB del informe se puede retirar con seguridad.

Si el guardado falla, lea el error exacto, corrija el problema y vuelva a elegir Guardar el informe en USB. Si la memoria USB del informe sigue conectada, no hace falta desconectarla antes.

Si no se puede guardar ningún informe, lea las líneas Código de soporte y Compilación de la pantalla y comunique esos valores exactos al soporte técnico. No incluyen números de serie ni rutas de los discos.

Si se rechaza la memoria USB:

  • Sistema de archivos o estructura incorrectos: utilice otra memoria USB con un solo volumen FAT32 o exFAT.
  • Ya montada: desconecte solo la memoria USB del informe, vuelva a conectarla y vuelva a intentarlo.
  • Más de una memoria USB nueva: desconecte las demás para que quede exactamente una.
  • Afecta al disco de arranque o al disco seleccionado: primero apague y luego ordene las memorias USB con el equipo apagado.

Apagar y retirar las memorias USB

  1. Primero el informe: mantenga la sesión abierta, guarde el informe y espere la confirmación de guardado. Solo entonces se puede retirar la memoria USB del informe.
  2. Deje conectados la memoria USB Beamo y el disco borrado mientras Beamo Wipe esté en marcha.
  3. La memoria USB Beamo solo se puede retirar con seguridad cuando el equipo esté completamente apagado. Retirarla antes termina la sesión de inmediato.
  4. Si reinicia en lugar de apagar, deje conectada la memoria USB Beamo para volver a Beamo Wipe. Todo lo que no esté guardado se pierde igualmente.
  5. Si hay más de una memoria USB conectada, o si se desconectó y volvió a conectar algo, no adivine cuál es cuál. Primero apague y luego ordene las memorias USB con el equipo apagado.
